## Four Beats

1. **Name the cut.** Give the Rocscience Slide2 session a short title before you edit the slope section.
2. **Pin the live layers.** Keep current soil, rock, and the slip surface on the Rocscience Slide2 board and leave unused trials aside.
3. **Check the result.** Read the Rocscience Slide2 summary before you move a water line or a material boundary.
4. **Close the loop.** Note which stability result is governing so the next Rocscience Slide2 visit does not start by redrawing the section.

## Field Note

Rocscience Slide2 is easier to trust when the section stays smaller than the hillside it came from. A named session shows which cut is active, the pins show which material layers you will read today, and the closing note tells the next person which slip surface governs the stability results. That record is short on purpose: not a copy of every trial, only the path back to the section that is still open.

The same loop fits a student slope, a client embankment, or a computer shared by two reviewers. Open the last Rocscience Slide2 session, confirm one slip surface, and leave the stability result easier to find than you found it. Borehole logs stay where they are. Rocscience Slide2 only holds the slope section, the summary, and the handoff.

## One Real Pass

Pick a cut that already has a name: a road embankment, a pit wall, or a simple two-layer slope. Open it in Rocscience Slide2, keep only those material layers on the board, and read one stability result you can point to. A pass is done when that result sits beside the slip surface and the unused trials are no longer in the way. Rocscience Slide2 does not need a full redraw of the site before it is useful.

If the pass feels crowded, the section is too wide. Drop anything that belongs to a different cut and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first layer to the slip surface, with the summary still matching the stability results on the board.
